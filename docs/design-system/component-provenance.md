# Component provenance

Records every external component incorporated into Dharma Granth: source, licence, whether modified, dependencies added, files, and review date.

## Incorporated so far

**None.** As of 2026-10-19 no code from shadcn/ui, Radix, Magic UI, React Bits, Aceternity or any other external component library has been copied or installed. The components in the repository (reading-depth switch, breadcrumbs, offline manager, story deck, quote studio, navigation drawer) were written in-house. They use lucide-react icons and framer-motion, which were already dependencies.

## Licence notes to carry forward

- **shadcn/ui, Radix, Magic UI, cmdk, vaul:** MIT. Keep the copyright notice with copied source files (a comment header is enough) and list them here.
- **React Bits:** MIT plus Commons Clause. Allowed in a website; not allowed to sell or redistribute the components themselves. Do not copy any React Bits code until this is signed off, and never republish it as a pack or template.
- **Aceternity UI:** licence unverified; some components are paid. Do not use.
